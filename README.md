# Тестовое задание для EmployCity

## 🌐 Демо

https://katytrop.github.io/test-employ/

## 📁 Структура веток

- `main` — информация о проекте
  
- `dev` — основная ветка разработки
  Здесь находятся исходные файлы:  
  - SCSS  
  - JS (не сжатый)  
  - исходники
    
- `gh-pages` — собранная версия проекта  
  После сборки с помощью Gulp все стили, исходники и скрипты минифицированы.

## ⚙️ Технологии

- Gulp
- SCSS
- JavaScript (ES6+)
- BEM

## 🚀 Сборка и запуск ветки dev

npm install     # Установка зависимостей
npm run dev     # Запуск проекта на ветке dev
